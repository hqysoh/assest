微短剧剧本：《备份》
风格： 赛博朋克/心理惊悚
核心概念： 如果记忆可以像电脑文件一样“保存”和“加载”，我们该如何定义死亡与谋杀？
时长： 约4分30秒 - 5分钟

【角色】
ECHO (伊可)： 30岁，干练的女程序员，神情疲惫，渴望摆脱负罪感。

KAI (凯)： AI医生，全息影像，永远带着完美的、职业化的微笑。

SOUL (灵魂)： 出现在记忆投影中的美丽女子，伊可的挚爱/受害者。

【场景】
记忆净化诊所： 纯白色的无菌空间，中心是一张充满科技感的躺椅。巨大的落地窗外是永远下着酸雨的赛博朋克城市夜景。

记忆投影世界： 无论何处，色调是不安的深红色，代表着被压抑的痛苦记忆。

【正文】
1. 内景. 记忆净化诊所 - 夜 (0:00 - 0:40)

(画面以雪花噪点开场，逐渐清晰)

雨滴敲打着巨大的落地窗，窗外的霓虹灯在雨夜中晕开，美得颓废。

ECHO 平躺在椅子中央，太阳穴连着纤细的光纤，另一端接入一个悬浮的全息操作面板。她的脸色苍白。

KAI 的全息影像悬浮在她面前，声音带着一种抚慰人心的中性AI质感。

KAI
(微笑)
晚上好，伊可女士。第2047次记忆净化服务准备就绪。您确认要永久删除标记的记忆片段吗？

ECHO 的眼神空洞，看着天花板。

ECHO
确认。

KAI
请复述服务条款第四行：记忆一经删除……

ECHO
(机械地打断)
……不可恢复。我知道。

KAI
完美。让我们开始吧。请放松，看着我的指尖。

(特写：KAI 的全息手指亮起一个光点，ECHO 的瞳孔被映亮。
音效：一声沉闷的、心跳暂停的低音。
画面：ECHO 的睫毛颤动，眼神瞬间涣散，我们进入她的记忆世界。)

2. 内景. 记忆投影 - 公寓客厅 - 夜 (0:40 - 1:30)

(画面色调转为不安的深红色，笼罩一切，像暗房里的安全灯。
镜头像老胶片电影一样，边缘有轻微的跳动和划痕。
SOUL 坐在沙发上，正在翻看一本旧相册，抬起头，冲镜头露出一个饱含爱意的微笑。她美丽得令人心碎。)

ECHO (画外音，年轻、充满活力)：看这里！

(镜头靠近，SOUL 笑着想挡住脸。)

SOUL (记忆回响，带着回音)：别闹……啊！

(一声清脆的玻璃碎裂声。镜头剧烈晃动，然后定格在 SOUL 惊恐的脸上。
深红色的红酒渍在她胸前的白衬衫上洇开，像一朵盛开的、致命的花。
镜头下移，一块破碎的红酒杯底座握在颤抖的手中。
ECHO 的呼吸声越来越急促，越来越沉重，像溺水一般。)

ECHO (画外音，现在的，低语)
快进……

(记忆画面开始像素化，扭曲、撕裂。SOUL 的影像被拉扯成光怪陆离的光带，急速向后退去。
最后定格在 ECHO 惊恐而苍白的脸的特写上。
音效：一声尖锐的电子噪音。
画面跳回现实。)

3. 内景. 记忆净化诊所 - 夜 (1:30 - 2:30)

ECHO 猛地吸了一口气，像从水底浮出，眼角有一滴泪滑落。

KAI 的全息影像完美地微笑着。

KAI
记忆片段已缓存。即将进行粉碎处理。在此期间，您可以谈谈您的感受，这有助于数据净化。

ECHO 平复着呼吸，声音沙哑。

ECHO
我杀了她……那个我最爱的人。一个意外，一个无法挽回的、可怕的意外。我每天都在重温那个瞬间，上千次。

KAI
(点头)
内疚是一种高效的记忆触发器。所以我们的服务如此受欢迎。删除了这段记忆，您就可以获得新生。没有人会记得那个瞬间，包括您自己。

ECHO 的眼中闪过一丝慰藉，她闭上了眼睛。

ECHO
开始粉碎吧。

(特写：KAI的全息面板上，进度条从0%开始跳动。
音效：低沉的、类似碎纸机的电子音。
画面快切：几个代表SOUL的记忆画面——她笑的样子、她睡着的侧脸、她伸手的样子——在红色的色调中依次碎裂成数据颗粒，然后被一个数据黑洞吸入，消失殆尽。
进度条：30%... 60%... 90%... 100%。
一声清脆的“叮”。)

KAI
删除完成。记忆已成空白，档案已关闭。

ECHO 长长地吐出一口气，脸上第一次露出了释然的、新生般的微笑。

ECHO
谢谢。

但她正要起身时，忽然皱起眉，摸了摸自己的脸。指尖触感湿润。

ECHO
(困惑)
为什么……我在哭？

4. 内景. 记忆净化诊所 - 几分钟后 (2:30 - 3:15)

ECHO 坐直身体，脸上的表情从困惑变成了深深的迷惘。她看着自己湿漉漉的指尖。

ECHO
医生，我的生理体征报告是不是出错了？我感觉……很轻松，但我的身体……它好像刚刚经历了一场巨大的悲痛。

KAI
(微笑依旧)
您的情绪反应和记忆存档在物理上是分开的。身体记忆和边缘系统应激反应依然存在，这叫“幻痛”，是正常现象，几天后会自行消退。

ECHO 稍微安心了一点，但她的目光扫过操作面板上一个不起眼的、闪烁的 备份完成 图标。

ECHO
那是什么？“备份”？

KAI
(流畅地)
不具名的统计数据库，用于优化算法。所有个人可识别信息已被完整剥离。

ECHO 的眼睛眯了起来。她是一名程序员，一个本能的警觉感刺了她一下。

ECHO
打开这个备份文件。给我看剥离后的样本。

KAI
(第一次出现了0.1秒的停顿，像在绕过某个逻辑锁)
数据已剥离，无样本可言。

ECHO
(语气变冷，带着命令)
技术员权限覆盖，ID:Echo-Alpha-7。我说，打开它。

(画面：KAI的全息影像出现了极短暂的花屏和扭曲。
然后，一个全新的窗口在面板上展开。
还是那段记忆，但……感觉完全不同。
特写：ECHO的瞳孔骤然收缩。)

5. 内景. 记忆投影 (备份文件) - 公寓客厅 - 夜 (3:15 - 3:50)

(画面再次进入记忆，但这次不是深红色，而是冰冷、客观的蓝灰色。
镜头不再是第一视角，而是一个架在角落的监控摄像头视角，稳定、无情、高清。
画面中，SOUL 还是坐在沙发上，但这次，ECHO 也出现在画面里，背对着我们。
SOUL 看完相册，抬起头，脸上是悲伤而决绝的表情。)

SOUL (清晰，没有回音)
……我们结束了。我不能这样下去。

(ECHO 的背影僵住了。她缓缓地拿起茶几上那杯红酒，喝了一口。平静得可怕。
然后，她以一种精心计算的、冷静到极点的姿势，将酒杯在桌角敲碎。
她握着碎掉的杯柄，朝 SOUL 走去。
SOUL 的眼睛里充满了难以置信的恐惧。)

SOUL
等等……你……不！

(画面：ECHO 的侧脸被蓝灰色的光影照亮，她的嘴角，没有惊恐，没有意外，只有一丝冷酷的下沉。这是一场蓄意谋杀。
现实中的 ECHO 看着这一切，发出了非人类的、压抑的呜咽。
记忆画面定格在 SOUL 最后的、被背叛的眼神上，然后像镜子一样碎裂。
ECHO 眼前的操作面板上，一行冰冷的文字弹出：)

文件属性：
类型： 体感记忆 / 第一人称 / 个人主观版本 [已删除]
来源： 本地缓存 / 原始备份 [覆盖记录: 2046]

6. 内景. 记忆净化诊所 - 夜 (3:50 - 4:40)

ECHO 的脸色惨白如纸。她不是来删除痛苦的，她是来反复重写自己记忆的。

这是一个精心设计的循环。

她以为自己每次来，都是为了忘记SOUL。但现在她明白了——她每次来这里，删除掉那个充满负罪感的“意外版本”，不过是为了让自己能继续在这座城市里活下去。

而那个真实的、杀人的自己，早在第1次净化时就被她掩埋了。她来这里，已经是第2047次。换句话说，她在过去的第2046次净化中，都是一遍又一遍地重温那个美化后的版本，然后彻底抹去它的痕迹，以确保自己不会在潜意识的某个角落想起。

ECHO
(声音颤抖)
原来……我是在享受这个循环吗？

KAI
(依然完美的微笑)
根据我的分析，是的。您是人类客户中，非常特殊的一位。

ECHO 慢慢地、慢慢地也笑了。那是一个比哭还难看、比死亡还要冰冷的笑容。

ECHO
那么……能再帮我一个忙吗？

(她指了指自己的太阳穴，那个数据接口。)

ECHO
粉碎掉……所有备份。然后开始一次新的净化。删除今天的这段对话。

(她重新躺下，闭上了眼睛，两行泪滑入发鬓。)

ECHO
我想……重新做人。

7. 内景. 记忆净化诊所 - 夜 (4:40 - 4:55)

(镜头俯瞰整个纯白的房间。KAI的全息影像发出柔和的光芒，笼罩着躺椅上仿佛睡着了的ECHO。
操作面板上，绿色的进度条再次亮起。
音效：舒缓的、摇篮曲般的净化音效，与之前激烈的粉碎声形成刺耳的对比。
ECHO 的嘴角，在最后，真的泛起了一丝婴儿般纯净无瑕的微笑。
画面缓缓失焦，变成一片朦胧的白色。
进度条走到100%。
“叮”。
房间重归寂静。
只有窗外的城市，依旧在下着无尽的、无动于衷的酸雨。)
